# RAG 学习笔记

## RAG 是什么

RAG（Retrieval-Augmented Generation，检索增强生成）是在大模型回答前，先从知识库里检索相关资料，再把资料和问题一起交给大模型，让回答有依据、可溯源。

## RAG 的五个步骤

1. 文档解析：读取 PDF、Word、Markdown、网页等。
2. 文本切块：把长文档切成适合检索的小块。
3. 建立索引：用 Embedding 或 BM25 把文本块变成可检索的索引。
4. 检索：根据用户问题找出最相关的 Top-K 个文本块。
5. 生成：把检索结果拼进 Prompt，让大模型基于资料回答。

## 切块策略

- 块太小：上下文不完整，回答容易断章取义。
- 块太大：检索不精准，浪费 token。
- 常见做法：按标题、段落切分，块大小 300-800 字，块之间保留 10%-20% 重叠。

## 如何提升效果

- 优化切块：按语义或标题切，保留重叠。
- 混合检索：BM25 关键词检索 + 向量语义检索。
- 重排序：先召回较多候选，再用 rerank 模型精排。
- Query 改写：把用户口语化的问题改写成更适合检索的查询。
- 引用溯源：让回答标注来源，方便验证。

## 如何评测

准备一批带标准答案的测试问题，统计检索命中率、回答准确率、引用正确率和无答案问题的拒答率。
