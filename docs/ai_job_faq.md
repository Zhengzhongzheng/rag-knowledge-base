# AI 应用开发岗位常见问题

## 这个岗位每天做什么

AI 应用开发工程师负责把大模型接入真实产品，常见工作包括：调用模型 API、设计 Prompt、搭建 RAG 知识库、实现 Agent 工具调用、做效果评测、优化成本和延迟，以及把应用部署上线。

## 需要哪些技能

- Python 和 FastAPI
- 大模型 API 与 Prompt 工程
- RAG：文档切块、Embedding、向量检索、重排序
- Agent：Function Calling、ReAct、MCP
- 工程化：Git、Linux、Docker、数据库
- 会用 Cursor、Claude Code 等 AI 编程工具

## 面试常问的问题

1. RAG 的完整流程是什么？
2. 文档为什么要切块，切多大合适？
3. 如何提升检索召回率？
4. 大模型出现幻觉怎么办？
5. Agent 的 ReAct 循环是什么？
6. 如何评测一个 RAG 系统的效果？
7. 如何降低 token 成本和响应延迟？
8. MCP 解决了什么问题？

## 双非本科生怎么突围

用可演示的项目证明能力，而不是只靠学历。建议准备两个项目：一个 RAG 知识库问答，一个 Agent 工具。项目要能在线访问，GitHub 有完整 README，面试时能讲清楚技术选型、难点和优化效果。
