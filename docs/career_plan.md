## 二、技能栈（分四层，从下往上打）

### L0 地基（会就快速过，不会就补）
- Python（主力）：语法、函数、类、装饰器、生成器、异常、虚拟环境
- Git / GitHub：add、commit、branch、PR、rebase
- Linux 基础：常用命令、文件权限、进程、看日志
- Docker：镜像、容器、Dockerfile、docker-compose（够部署用即可）

### L1 AI 应用核心（这是你的主战场）
- 大模型 API 调用（DeepSeek / 通义千问 / GPT）
- Prompt 工程：角色设定、结构化输出、少样本、思维链
- Function Calling / Tool Use（让模型调用工具）
- RAG（检索增强生成）：切片 → Embedding → 向量库 → 检索 → 生成
- 向量数据库：Chroma（入门）→ Milvus / pgvector（进阶）
- Agent：ReAct 思路、多工具调用、多轮任务
- 框架：LangChain / LlamaIndex（会用一个即可，更推荐能自研轻量版）

### L2 进阶（拉开差距的加分项）
- MCP（Model Context Protocol）：让模型接外部工具/数据源
- 微调基础：LoRA 微调一个小模型做垂直任务，并会做评测对比
- 评测（Eval）：怎么衡量模型答得好不好（面试官最爱深挖）
- 成本优化：模型选型、缓存、Prompt 精简、上下文长度控制
- 多模态 / 语音（选学，用于差异化）

### L3 工程化 + 面试
- FastAPI 后端 + 简单前端（Streamlit / Gradio / React 能看懂）
- 数据库（MySQL / PostgreSQL）+ Redis 基础
- 云部署：任意云服务器把 demo 跑起来（有公网地址）
- 算法：剑指Offer + LeetCode Hot 100（主攻简单+中等）
- 八股：OS / 网络 / 数据库 / 并发 / Python 基础

### L4 必备工具（2026 年硬性要求）
- AI 编程工具：Cursor / Claude Code / Copilot（会用是默认要求，不是加分）

## 四、3 个能写进简历的项目（具体怎么做）

### 项目1：RAG 企业知识库问答（11 月做）
- **一句话**：上传文档，AI 基于文档内容回答，带引用溯源。
- **技术栈**：Python + FastAPI + LangChain/LlamaIndex + Chroma/Milvus + Streamlit + Docker
- **核心功能**：
  - 支持 PDF / Word / Markdown 多格式解析
  - 智能切片（按语义/长度/标题）
  - 混合检索 + rerank（重排序提升准确率）
  - 答案引用溯源（展示来源段落）
  - 多轮对话 + 流式输出
- **加分做法**：选一个真实场景，比如“2027 届秋招信息知识库”或“某公司产品手册问答”
- **交付标准**：GitHub 可运行 + 公网 demo + README + 演示视频

### 项目2：AI Agent 工具（12 ~ 1 月做）
- **一句话**：让 AI 不只会回答，还会调用工具完成任务。
- **选题方向**（选一个）：
  - AI 简历诊断 / 模拟面试教练（上传简历 → 打分 → 追问 → 生成面试题）
  - AI 学习规划助手（拆解目标 → 生成计划 → 调用日历工具）
  - 校园 / 求职信息助手（Function Calling 查数据库）
- **技术栈**：Function Calling / 自研 Agent + MCP + 数据库 + 前端
- **加分做法**：接入 MCP，做多工具协同，并写一份“评测”说明效果

### 项目3（可选，差异化加分）：LoRA 微调小模型
- 用 Qwen-7B 等级的小模型，LoRA 微调一个垂直任务（如客服话术、简历分类）
- 重点展示：数据准备 → 微调 → 评测对比（微调前 vs 微调后）

## 五、面试准备清单

### 算法（双非主攻简单+中等）
- 剑指Offer + LeetCode Hot 100
- 重点：数组 / 字符串 / 链表 / 栈队列 / 二叉树 / 回溯 / 动态规划基础

### 八股
- OS：进程线程、内存管理、死锁、虚拟内存
- 网络：TCP 三次握手、HTTP/HTTPS、GET vs POST
- 数据库：索引(B+树)、事务、隔离级别、MySQL
- 并发：锁、乐观锁悲观锁、Redis 基础
- Python：装饰器、生成器、GIL、深浅拷贝、可变/不可变

### AI 应用专项（这个方向面试官最爱深挖）
- RAG 完整流程、为什么要切片、怎么切
- 如何提升召回率 / 准确率（混合检索、rerank、优化切片）
- 幻觉怎么缓解、上下文太长怎么处理
- Agent 的 ReAct 原理、多工具如何调度
- 如何评测大模型效果（这是拉开差距的题）
- 模型怎么选型（DeepSeek / Qwen / GPT 的取舍）
- 成本怎么优化、流式输出怎么做
- MCP 是什么、解决什么问题

## 六、镀金 / 个人 IP 行动（边学边攒）

### 优先级排序：求职主线 80% > 项目/开源 > 内容 IP 10-15% > 接单 5-10%

- 每周至少 3~5 次 commit

## 八、三条铁律

1. **主线 80%**：最后这 8 个月，任何副业/IP 都不能挤占求职和项目。
2. **先交付再完美**：项目先做出能演示的 MVP，再迭代打磨，别在前期死磕细节。
